# ADR-004 — PostgreSQL Row Level Security

## Status

Aceito. Implementação na Fase 3.

## Contexto

Filtro no ORM sozinho falha com um `findById` descuidado. Precisamos de uma segunda barreira.

## Decisão

RLS em toda tabela tenantada. `SET LOCAL app.current_tenant_id` na mesma transação. Role da app com `NOBYPASSRLS`. Super Admin não recebe bypass amplo nas tabelas de cliente.

## Consequências

Jobs e workers também setam o contexto. Migrations usam role separada.
